# AGRILEASE starter kit
- `prototype/agrilease-prototype.html` – the full clickable prototype (React, browser storage). Demo logins: farmer@agrilease.ph / Farmer123, owner@agrilease.ph / Owner123, admin@agrilease.ph / Admin123.
- `database/schema.sql` – MySQL schema for Laragon (docx section 10 + subscriptions).
- `docs/GITHUB_PLAN.md` – who does what, branches, commits, pull requests, merge order.
- `docs/SETUP_GUIDE.md` – step-by-step setup.
- `assets/official-qr-placeholder.png` – placeholder QR to replace with the real GCash QR.
Backend (Node.js + MySQL) and frontend (React + Vite) source code are not in this kit yet.
